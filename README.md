## Описание работы
В ходе данной работы написано веб-приложение с нуля на стандартных модулях (**http.server**, **urllib**, **sqlite3**, **os**), которое запускается локально в localhost. Представлено 2 версии веб-приложения: 
* **server.py** (с уязвимостями);
* **server_save.py** (с устраненными уязвимостями).

Разница между программами представлена в файле **patch.diff**.

Уязвимости эксплуатируются с помощью скриптов:
* **script_sql.py** (для эксплуатации SQL-инъекции);
* **script_xss.py** (для эксплуатации XSS-уязвимости).

## Работа программы
В веб-приложении представлены поля ввода учетных данных (логин и пароль). А в базе данных пользователей находятся только данные администратора. После ввода пользователем данных веб-приложение динамически формирует и возвращает страницу ответа с результатом выполнения запроса.
* При успешном вводе данных администратора появляется надпись **"Успешно! Вы вошли как админ"**;
* При неудачной попытке входа появляется надпись **"Неверный логин или пароль. Вход запрещен"**.

В скриптах для эксплуатации уязвимости для проверки успешной эксплуатации используются эти маркеры. Скрипт обращается к веб-приложению (с помощью модуля **requests**), отправляет туда вредоносную нагрузку и принимает ответ. В ответе он ищет маркеры, чтобы понять, успешна ли эксплуатация уязвимости, и выводит на экран результат.

## Устранение уязвимостей
* Для устранения **SQL-инъекции** используются параметризованные запросы. Вместо подстановки данных прямо в строку запроса (через f""), на место переменных ставятся знаки вопроса **?**, а сами данные передаются базе данных отдельно в виде кортежа (tuple).
* Для устранения **XSS-уязвимости** используется превращение опасных спецсимволов HTML в их безопасные текстовые аналоги с помощью функции html.escape(). Так, браузер не сможет запустить такой код как скрипт.
